## 3 从这些案例里能提炼的七条结构规律

1. **目标要三重锚定**：国家/行业需要 + 岗位真实痛点 + 我的一手经历。缺任何一条，评委都会觉得"这岗位换谁都能讲"。
2. **岗位名要具体**：写"电池测试工程师""照护主管""牧区财务专员"，不写"新能源行业""大健康领域"。
3. **一手经历放在前 3 页**：获奖案例的开场都是"一件事"，不是"一个行业趋势"。趋势放到第 3–4 页做背景。
4. **证据要能当场拿出来**：标本、笔记、台账、签字、证书编号。照片次之，形容词最不可信。
5. **数字必须带口径**：±0.05mm、10⁷ 拷贝数、6 个 9、126 小时、97 份——都能回答"谁测的、什么条件、什么时候"。
6. **差距自己先说**：报道里反复出现"不足与调整"，这是评分维度里"优化改进 / 发展潜力"的落点，藏短板反而扣分。
7. **打磨在内容不在特效**：35 稿、100 多遍的复盘说明，赢的是逻辑与表达密度，不是动画。

## 4 落到页面上的做法（按组别）

### 成长赛道（Z1 / Z2）

- 用 **timeline** 讲"哪一步让我变了"，每节点配一句 `detail`（当时的判断或代价），不做履历罗列。
- 用 **detail** 页写"一次经历教了我三件事"，把感悟拆成可验证的判断。
- 职教组（Z2）优先写**作品/工艺/服务对象**：邹娟的地方食材、罗雨松的精度，都是"手上功夫"上版。

### 就业赛道（Z3 / Z4 / Z5）

- 用 **evidence** 页做"证据清单"：证据—证明什么—出处，四列对齐，评委会顺着核。
- 用 **matrix** 做自我诊断：横轴"岗位使用频率"、纵轴"我的掌握程度"，四格各一句，比"我还有很多不足"有说服力。
- 用 **cards** 拆"这个岗位一天在做什么"（方案/执行/判定/协同），证明你懂岗位而不是懂行业。
- 职教组（Z5）加**安全与规范**一页：这是职教组和本科组最容易被区分的地方。

### 研究生组（Z4）

- 把"参与深度"写清楚：在哪个项目里负责哪一段、产出被谁采用。焦启龙式的"参与国家重点研发计划"要配具体分工，否则像挂名。
