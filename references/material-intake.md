# 素材卡：把散材料收成 18 个字段，缺哪格就补哪格

PPT 做不出来，八成不是排版问题，是**素材没到位**。所以第一步不是打开 PPT，而是把下面这张卡填满——填不满的格子就是缺口清单，也是答辩必被问的地方。

## 1 素材卡（18 字段）

| # | 字段 | 要什么 | 从哪来 |
| --: | :--- | :--- | :--- |
| 1 | 组别 | Z1–Z5 | 用户告知；不确定就问"本科/研究生/职教""成长赛道还是就业赛道" |
| 2 | 姓名 | 展示用姓名 | 材料封面、简历 |
| 3 | 学校/层次 | 学校 + 层次（本科/高职/研究生） | 简历、报告 |
| 4 | 专业/年级 | 专业全称 + 年级 | 同上 |
| 5 | 目标岗位 | **岗位名 + 单位类型 + 地域**（三件齐全） | 简历求职意向、报告目标章节 |
| 6 | 岗位来源 | 招聘公告 2–3 条硬要求的原文 + 年份 | 招聘网站截图、公告 PDF |
| 7 | 政策/行业锚点 | 一个战略 + 一个可查指标 | 规划文件、协会年报、白皮书 |
| 8 | 一手见闻 | 一次"亲眼所见"的具体场景（时间、地点、人物、细节） | 报告叙事段、访谈记忆 |
| 9 | 硬证据 | ≥3 项：证书/项目/实习/作品，每项带口径 | 证书扫描、项目文档、工单 |
| 10 | 过程证据 | 频次、时长、角色（"独立/主导/参与"） | 台账、日志、带教评价 |
| 11 | 差距 | 1–3 条，对照 JD 写 | 对照表（自己做） |
| 12 | 行动路径 | 12 个月内可验收的动作 | 报告规划章节 |
| 13 | 备选 | 1–2 个邻接岗位 + 触发条件 | 报告备选章节（多数人缺） |
| 14 | 签名句 | ≤30 字，含"身份 + 动作 + 对象" | 自己写，或从陈述稿末尾提炼 |
| 15 | 可公开图片 | 实习现场、作品、流程示意（含授权说明） | 手机相册、项目资料 |
| 16 | 数据口径 | 每个数字的"谁统计、什么范围、什么时候" | 报告脚注、台账 |
| 17 | 评分维度落点 | 每页服务哪个维度 | 见 `page-skeletons.md` |
| 18 | 缺口清单 | 上述任何一格的缺失 | 自动汇总进审计报告 |

## 2 材料 → 字段的抽取映射

先跑 `scripts/extract_content.py <文件>` 拿到带页码锚点的全文，再按材料类型对号入座：

| 材料 | 主要贡献 | 不要从里面拿什么 |
| :--- | :--- | :--- |
| 生涯发展报告（docx/pdf） | 字段 5、7、8、11、12、13 | 整段照搬（PPT 放不下） |
| 求职简历（docx/pdf） | 字段 2、3、4、5、9、10 | 简历式罗列（"负责…协助…"） |
| 现有 PPT（pptx） | 已有表述与图片（字段 9、15） | 沿用旧版式（多半超载） |
| 证书 / 工单 / 截图 | 字段 9、10、16 | 未打码的身份证号、他人信息 |
| 招聘公告 | 字段 6（逐条抄硬要求） | 薪资截图（易引争议） |
| 政策文件 | 字段 7（战略 + 指标） | 大段原文（改成一句人话） |

## 3 缺口怎么补（不许编）

缺素材时按顺序选替代方案，**替代方案也要写进报告的 `gaps`**：

| 缺口 | 可接受替代 | 不可接受 |
| :--- | :--- | :--- |
| 没有企业实习 | 实验室跟岗、课程项目、校企合作实训、暑期实践 | 编造实习单位 |
| 没有政策指标 | 行业协会年报、招聘平台岗位数趋势、地方产业规划 | 虚构数字 |
| 没有现场照片 | 流程图/示意图/作品截图 + 说明"示意" | 用网图冒充现场 |
| 没有排名/绩点 | 课程通过率、项目验收结论、带教评价 | 编造名次 |
| 没有获奖 | 用"过程证据"替代（频次、时长、交付物） | 把参与写成获奖 |
| 没有备选岗位 | 用同能力栈邻接岗位推导（说明重合的三条能力） | 空着不写 |

## 4 三条隐私与合规底线

1. **照片**：出现他人正脸、患者、未成年人、涉密设备的，一律打码或换图；写明"已获授权"。
2. **单位与项目名**：未公开的项目用"某电池厂""某三甲医院"替代，交付物可以脱敏截图。
3. **数据**：只用在材料里能自证的数；内部数据不上版，宁可写区间也不写假精确值。

## 5 素材卡的最小可用集

如果时间只够填 8 格，优先这 8 个——缺任何一格，PPT 都撑不起来：

1 组别、5 目标岗位（三件齐全）、6 岗位来源、7 一个可查指标、8 一次一手见闻、9 三项硬证据、11 差距、14 签名句。
